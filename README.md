# 돌림판 점심 메뉴 선택기

간단한 정적 웹 앱으로 스타트 버튼을 눌러 돌림판을 돌리면 분식, 피자, 비빔밥, 도시락 중 한 메뉴가 무작위로 선택됩니다.

## 실행 방법

가장 간단한 방법은 `index.html` 파일을 웹 브라우저(Chrome, Edge, Firefox 등)로 직접 여는 것입니다.

1. 이 저장소를 다운로드하거나 클론합니다.
2. `index.html` 파일을 더블 클릭하거나 브라우저에서 “파일 열기” 기능을 이용해 엽니다.
3. 돌림판이 보이면 `<스타트>` 버튼을 눌러 메뉴를 선택하세요.

### 간단한 개발용 서버에서 실행하기

정적 파일 서버를 이용하면 다른 기기에서도 접속하거나 CORS 관련 문제를 피할 수 있습니다.

1. 터미널에서 프로젝트 디렉터리로 이동합니다.
2. 아래 명령어를 실행해 Python 내장 서버를 띄웁니다.
   ```bash
   python -m http.server 8000
   ```
3. 브라우저에서 <http://localhost:8000/> 로 접속합니다.
4. 화면에서 `<스타트>` 버튼을 눌러 돌림판을 돌립니다.

원하는 포트 번호가 있다면 `8000` 대신 다른 값을 사용해도 됩니다.
